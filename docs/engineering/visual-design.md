# 视觉规范

PiArc 桌面界面的视觉方向是无边框、低噪声、排布整齐。层次靠填充色、留白和细分隔线建立，不靠描边卡片；文案只写必要的一句。新界面按本规范设计，改动旧界面时顺带向它靠拢。颜色、字号、间距、圆角仍然只取设计令牌（ADR-0029），本规范规定怎么用它们。

基准样例是设置页原型（2026-11-27 定稿，见 ADR-0101）：会话侧栏横向滑成设置导航，主区换成居中单栏的设置页。

## 1. 层次

- **不用描边区分区域。** 区域之间的边界靠背景色差（侧栏 `workbench.navigation`、主区 `workbench.canvas`、输入卡片 `workbench.editor`）。描边只留给需要明确轮廓的输入卡片与浮层，并且用 1 px 的 `session.line` 环（`box-shadow: 0 0 0 1px`），不用 `border`。
- **主区是一张卡片（ADR-0105）。** 侧栏底色铺满窗口，主区（含工具分块）与设置页放在其上：靠侧栏两角 `radius-lg` 圆角加一圈 `session.line`，顶、右、底贴窗口边。卡片内各区域之间的线（标题栏下沿、工具分块之间）同样是 `session.line` 的细线；`border.subtle` 与它同值。侧栏底部不画分隔线。
- **不做卡片套卡片。** 一组记录（服务商、MCP 服务器、规则）直接排成行，行与行之间是 1 px 的 `session.line` 分隔线，不再外包一张带边框和背景的卡片。
- **用填充表达"可操作"与"状态"。** 次要按钮、选择器、分段控件的轨道用 `session.fill`；悬停用 `session.ghost-hover`；选中用 `surface.active` 或 `session.fill-hover`。状态徽标是浅色填充加同色系文字（成功、警告、强调），不加描边。
- **阴影只给浮层。** 菜单、弹出框、选择器面板用 `session.popover-shadow` 加 1 px 环；页面内的元素不加阴影。

## 2. 排布

- **单栏阅读宽度。** 设置页等表单类页面内容居中，最宽 720 px；对话区沿用 `session.measure`。两侧留白就是留白，不往里塞辅助面板（例如"本页目录"）。
- **行的结构固定。** 左边是名称（主文字色、中等字重）和至多一行说明（次要文字色、小一号），右边是控件，垂直居中。舒适密度行高不低于 60 px，紧凑密度不低于 50 px。控件列右对齐，同一页的控件右边缘对齐成一条线。
- **分节。** 分节标题用正文字号、半粗，下方一条分隔线，分节之间留 36 px 左右。页头是大标题（28 px 量级）加一句说明，和第一个分节之间留 28 px。
- **对齐网格。** 图标与文字的起点、行内控件的高度（28 或 32 px）、圆角（控件 8–10 px，浮层 12–14 px，输入卡片取 `workbench.composerRadius`）在同一页内一致。

## 3. 文案

- 每个设置项的说明至多一句，写"这个设置做什么"，不写实现细节、例外清单和背景故事。确实需要的细节放进提示（`data-tooltip`）或按需展开的区域。
- 页头说明一句话概括本页，不重复导航里的名称。
- 空状态一句话说明现状，加一个直接可用的操作；不写段落。

## 4. 交互状态

- 每个可悬停的元素都要在浅色和深色两种主题下看得出悬停与选中，截图核对。深色主题的 `surface.hover` 不能与它所在的背景同色（2026-11-27 修正：深色的 `surface.hover`、`surface.active` 各提一级）。
- 相邻的可悬停条目之间留 2 px 间隙，悬停底色与相邻的选中底色不能连成一片。
- 焦点环用 `c-focus-ring`，键盘焦点可见，鼠标点击不出现焦点环（沿用 `data-pointer-focus` 的规则）。
- 托管锁定、只读、不可用的控件降低不透明度并带标识，不隐藏。

## 5. 滚动条

- 滚动条只有滑块，没有轨道、底色和边框；平时透明，指针移到可滚动区域上才显示，宽度约 6 px（10 px 的命中区内收 3 px 透明边）。
- 滑块颜色用前景色的低透明度（浅色约 15%，深色约 18%），悬停在滑块上时加深。
- 不让滚动条在侧栏与主区的交界处形成第二条竖线。

## 6. 动效

- 视图之间的切换用形态变化而不是弹窗：侧栏内容横向滑动，主区内容淡入并轻微位移，时长取 `motion.slow` 量级，曲线取 `motion.curve-out`。
- 进入与退出对称；退出动画结束后再卸载内容。
- 尊重"减少动态效果"：时长令牌在该设置下为 0，组件不另读 `data-reduce-motion`。

## 7. 检查清单

交付界面改动前逐条核对：

1. 页面里没有描边卡片和卡片套卡片；分隔线都是 `session.line`。
2. 每条说明至多一句；没有大段解释。
3. 浅色、深色、紧凑密度三种状态都截图看过悬停、选中、禁用与焦点。
4. 滚动条只有滑块。
5. 中文与英文下都没有溢出和截断错位。
6. 切换动效在"减少动态效果"下立即完成。
