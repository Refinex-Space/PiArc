# 0101. 设置是工作台里的一个视图

- 状态：已接受（用户在 2026-11-27 确认原型后选定）
- 日期：2026-11-27
- 取代：ADR-0074 的"模态面板"形态（打开位置、背景保留与焦点归还仍按 0074）
- 修订：ADR-0073 在设置页一项上的范围
- 相关：架构文档第 8.2 节；ADR-0029（设计令牌）、ADR-0100；[视觉规范](../engineering/visual-design.md)

## 背景

ADR-0074 把设置做成工作台里的模态面板：遮罩盖住工作台，面板最大 1000 × 780，左侧 208 px 导航，右侧内容区。实际使用中，17 个页面都挤在这个面板里，长页面（模型与服务商、权限、MCP）要在小区域里滚动，内容区的宽度随窗口变化又放不开，页面之间的视觉也不一致。

ChatGPT 桌面端的做法是复用窗口本身：左栏从会话列表换成设置导航，主区换成设置页，页面内容居中成单栏。我们按这个思路做了 HTML 原型（`tmp/settings-prototype/`，不入库），用户确认了方向，并提出四点修改：去掉左栏的大标题、滚动条只留滑块、相邻悬停项之间留间隙、去掉右侧的"本页"目录。

## 决策

1. **设置是一个视图，不是弹窗。** 打开设置时，左栏的会话导航向左滑出，设置导航从右滑入；主区的会话淡出，设置页淡入。退出时反向。工作台保持挂载（会话、终端、草稿都不受影响），设置打开期间工作台 `inert`，退出后焦点回到打开它的控件。路由仍是 `#/settings/<id>`，入口（齿轮、⌘,、菜单、功能页的定位链接）不变。
2. **设置导航**：顶部是"返回"按钮（带 Esc 键帽）和搜索框，下面按"应用、模型、安全与网络、智能体、工具、支持"分组列出已注册的页面；按工作区区分的页面标"项目"。侧栏收起时，打开设置也显示设置导航。
3. **搜索结果在主区展示。** 输入后导航只留有命中的分组并显示命中数，主区按页面分组列出命中的设置项；↑↓ 选择，Enter 打开对应页面并把焦点放到该设置的控件上，目标行短暂高亮。Esc 先清空搜索，再退出设置。
4. **设置页**：内容居中，最宽 720 px；页头是标题加一句说明；按工作区区分的页面在页头右侧放工作区选择。页面按[视觉规范](../engineering/visual-design.md)排布：无边框、细分隔线、每项至多一句说明。
5. 主区顶栏显示"设置 › 页面名"；窗口按钮、拖动区域与会话视图一致。
6. 颜色模式用三张应用缩略图（跟随系统是左浅右深的拼合图）作单选，对比度、密度、减少动态效果用分段控件（ADR-0073 的规格）。记录类的行（服务商连接、账号）只把常用操作留在行内（测试连接、启用开关），编辑、删除、登出收进行尾的“…”菜单。
7. **按项目区分的页面在页头放范围选择**：药丸形轨道里是“全部”（用量页）与项目选择；项目选择是整块可点的原生下拉，指针点击不画焦点框。
8. **记录多的页面不无限下堆**：配置诊断按来源类别分标签，每类超过 12 条出现筛选并分批显示；Skills 超过 10 条同样处理；每条记录一行（名称、类别、状态与计数），细节收进可展开的区域，问题始终显示在它的行下。
9. **MCP 服务器可在页面添加**：本地命令（含环境变量）或 HTTP 地址，可用于所有项目（PiArc 用户 `settings.json`）或仅此项目（`.piarc/settings.local.json`，不进仓库）。写入前主进程弹原生确认列出命令或地址与变量名；Core 再校验定义、拒绝重名，项目本地的写入并入已有的信任决定，不再触发信任对话框。不支持在页面写 `headers`（可能是凭据），需要登录的 HTTP 服务器添加后在列表里登录（令牌进保险箱）。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 工作台内视图（左栏滑换、主区换页） | 空间与窗口一样大；与会话之间的切换自然；不另起导航层级 | 要处理两套侧栏内容的切换与焦点 | 采用 |
| 保留模态面板，只改内部样式 | 改动小 | 面板尺寸限制仍在，长页面依旧局促 | 不采用 |
| 独立设置窗口 | 可与工作台并排 | ADR-0074 已因窗口切换、输入隔离和焦点归还放弃 | 不采用 |

## 后果

- 正面：设置页获得完整的窗口宽度，长页面可读；设置与会话之间的切换是同一窗口里的形态变化。
- 负面与代价：Shell 需要在同一列承载两套侧栏内容；L4 中依赖 `.settings-dialog` 与 `role="dialog"` 的用例要改为依赖 `settings-window`。
- 需要配套做的事：架构第 8.2 节改写设置一段；`settings-workbench` L4 改测视图切换与搜索；各设置页按视觉规范逐页整理。

## 重新评估的触发条件

- 需要在看着某个会话的同时修改设置（例如边看边调权限规则），视图切换开始妨碍工作。
- 参考版本（ADR-0073）的设置形态有重大变化。
