# 0061. 无障碍与本地化的落地（补充）

- 状态：已接受，补充 ADR-0022、ADR-0029
- 日期：2026-11-21
- 相关：架构第 8.5、8.6、8.7 节；T43；NFR-06、NFR-07

## 背景

M1–M4 的界面各自做了部分无障碍与本地化，T43 统一收口并把能自动化的部分变成检查失败条件。基线（第 8.7 节）只写了原则：每行可读描述、节流的 polite 摘要、审批卡出现时移动焦点、全键盘、焦点环可见、中英文集中管理。下面是实现时定下的做法。全部依据 axe-core 4.14.0、Playwright 1.65.1 与 intl-messageformat 12.1.4 的锁定版本。

## 决策

1. **状态清单与覆盖。** 每个页面与组件状态一条（`apps/desktop/e2e/a11y/states.ts`，T43 时 57 条），L4 旅程逐条到达并在亮色与暗色下跑 axe（WCAG 2.0–2.2 A/AA 与最佳实践）。清单由 Vitest 与渲染进程的注册点比对：设置页、面板、渲染 `<Dialog>` 的文件、transcript 行 kind；漏登记即失败。违规一律修复，不禁用规则。
2. **transcript 是 feed。** 消息列表从 `role="log"` 改为 `role="feed"`，每行是带名称的 `article`（`row-label.ts`，名称与行显示的文字共用 i18n 消息），回合运行时 `aria-busy`。`log` 隐含 `aria-live`，会逐字播报流式输出，与"不逐字播报"冲突。
3. **节流播报。** 会话有一个 polite、atomic 的 live region：运行中的进展（当前工具、回复已写词数）至多每 5 秒一次（`LIVE_ANNOUNCE.intervalMs`），回合结束时播报一次结果（回复摘录或错误）。5 秒是读屏读完一句摘要并留出间隙的长度，比流式节奏慢一个数量级。
4. **审批卡取焦点。** 首张卡出现时焦点移到卡片容器，名称写明类型与对象；输入法合成期间等合成结束；出现后 400 ms 内卡片控件上的 Enter、Space 无效，与快捷键的防误触一致。审批快捷键不再拦截卡片与 composer 之外文本框里的按键（T42 的评论编辑框在等待审批时按 Mod+Enter 会被吞掉）。
5. **对比度在真实背景上成立。** 侧栏在 vibrancy / Mica 上叠一层 90% 的自身底色：axe 看不到系统材质、按白底计算，这层让任何背景下文字都达标，材质仍透出。代码高亮换成 GitHub 的高对比度主题（浅色的注释灰换成主题里更深的灰），每个 token 在代码与 diff 底色上不低于 4.5:1，明暗跟随应用的主题选择（I186）。diff 行号按钮的目标高度 24 px（WCAG 2.5.8）。
6. **强制颜色。** 主按钮用系统的 `ButtonFace`/`ButtonText`：Chromium 在文字后画 Canvas 色衬底，反色的按钮文字会被盖住。状态点与未读标记在强制颜色下保留系统色的形状（`forced-color-adjust: none` 只用于这些小标记）。
7. **本地化检查进 verify（第 16 步）。** `scripts/ci/check-i18n.mjs` 用 TypeScript 编译器 API 读目录、用应用自己的 intl-messageformat 解析 ICU：键集合一致、占位符一致、只用该语言有的复数类别、`t('…')` 引用存在、渲染进程与主进程没有硬编码的用户可见文字、不调不带 locale 的 `toLocaleString()`。固定写法（产品名）用 `i18n-exempt:` 注释说明理由。不新增依赖。
8. **数字与日期按应用语言。** 应用上下文提供 `format.number`、`format.dateTime`，按用户选择的语言而不是系统语言格式化。

## 影响

- verify 从 15 步变为 16 步；L4 新增 `t43-a11y`、`t43-keyboard`、`t43-approval-focus`、`t43-locales`。
- 中文目录里的 `one {…}` 复数分支从未生效（中文只有 `other`），改为 `=1 {…}`，单个工具调用的摘要恢复显示对象。
- 外链确认对话框、Markdown 的若干标签此前只有英文，现在走目录。

## 备选方案

- **用 `role="log"` 加 `aria-live="off"`**：语义仍是日志，读屏对 feed 的文章导航更合适，且 live 行为集中在一处更易控制。
- **侧栏在暗色下改为不透明**：会改变 T18 视觉关口确认的平台外观；90% 叠层保留材质又满足对比度。
- **为 axe 关掉 `color-contrast` 或 `region`**：任务要求不靠禁用规则通过，且真实问题（高亮颜色、按钮衬底）正是这些规则发现的。
