# 0070. 侧边对话的历史、工具与用量（补充）

- 状态：已接受
- 日期：2026-11-23
- 涉及：FR-CH-08、T49-A01 至 A06、架构第 6.15、8.2、9.2 节

## 决策

首问在 Agent Host 中创建 Pi 内存会话，取主会话当前分支上已完成的回合。主会话正在运行时，历史截止于本回合开始处。面板后续问题沿用这份历史与此前的侧边问答。每次打开面板分配独立标识；关闭面板、退出页面或关闭会话时中止请求并丢弃历史。

侧边请求复用主会话模型、system 与工具声明。声明用于保持请求前缀一致。侧边会话不注册可执行工具；模型请求工具时，Host 直接构造拒绝结果。提问与停止走独立的 AHP 方法，不进入主会话的 prompt、steer 或 follow-up 队列。

Core 按父会话记录服务商返回的 token，辅助用途为 `sideChat`。schema v13 在现有用量表中保存这类记录的工作区归属。即使首条主会话回复还未生成 JSONL，也能计入正确的工作区。索引重建保留这类无转录来源的用量；删除会话时一并删除。问题、回答和工具结果均不作为用量数据保存。
