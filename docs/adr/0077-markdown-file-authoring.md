# 0077. 会话文件面板中的 Markdown 编辑与本地图片（补充）

- 状态：已接受
- 依据：ADR-0022、ADR-0036、ADR-0076
- 日期：2026-11-24

## 一份原文，四种视图

即时编辑和源码共用一个 CodeMirror 6 文档状态、选区与撤销历史。首次浏览 Markdown 显示阅读视图，切换分栏时同时呈现可编辑源码和当前草稿的预览。文件保存继续由 Files 的会话草稿、原始版本校验和 Core 的原子写入负责。用户切换视图或临时回停靠不提交文件。编辑器按需加载，使用其所在窗口的 ShadowRoot 和构造样式表。

阅读视图的词法分析由独立 Worker 完成。GFM、标题锚点、任务列表、脚注、提示块和数学公式转换为结构化节点。KaTeX 输出由系统字体呈现的 MathML。Mermaid 的应用内引擎在专用的、不受信的本地文档中工作；工作台取得绘制结果后以图片显示。图表文档没有业务 preload 或项目文件授权，脚本、样式、图片和网络访问分别受该文档的 CSP 限制。应用来源不提供图表引擎的资源目录。会话消息继续使用原有的渲染路径。

## 图片设置与授权

用户选择使用本地存储。在设置的 Markdown 页选择文档目录、资源子目录、随文档命名的子目录、自定义相对目录、系统选择的目录，或保留已有文件引用；可选择链接的路径形式。选图、粘贴和拖入使用同一组规则。外部目录授权来自原生文件夹选择器，并记录目录身份；设置页面可以撤销。主进程发放短期的受控图片地址，Core 校验目录、格式与大小。网络图片显示为可主动打开的外部链接。图片操作不把文件上传到服务器。系统选图耗时较长时，主进程只给本次已确认的图片插入签发一次短期保存许可，绑定页面、会话、文档、原始修订和插入后的确切正文。

## 复用来源

Markdown Studio `e6ebd0c` 提供 CodeMirror 的 Markdown 扩展、原位表格与图片交互和文档语法的实现依据。Marklyra `e7c2175` 提供原文事务、模式切换和本地图片策略的依据，图片校验适配其 Rust 实现。具体移植路径、改动和 Apache-2.0 许可登记在 `third-party/sources.json`。平台桥接、设置持久化、保存冲突、系统窗口、主题与对话引用均由 PiArc 管理。

## 依赖选择

CodeMirror 6 与 Lezer 采用锁文件中的精确版本。KaTeX 0.19.1 按需加载并直接生成 MathML 节点。Mermaid 11.17.2 使用内置布局；参考项目的 Mermaid 12.1.0 声明了 EPL-2.0 的 ELK 依赖，PiArc 的发布依赖许可清单不包含该许可。Mermaid 的颜色库 khroma 2.1.0 在发行包内附完整 MIT 许可但缺少 npm SPDX 字段，审计须同时匹配包版本、锁文件完整性和实际许可全文。
