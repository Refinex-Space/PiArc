# 0080. 对话里的图表、图片、消息时间与命令芯片

- 状态：已接受（补充）
- 日期：2026-11-25
- 来源：用户在会话主块对标中的追加要求
- 相关：ADR-0022、0030、0036、0045、0076、0077、0078、0079；架构第 7.4、8.2、10.3 节

## 决策

1. **Mermaid。** 回复里的 ` ```mermaid ` 代码块用 Files 已有的隔离绘图文档（`files/markdown/diagram-client.ts`，ADR-0077）绘制，页面只收到 SVG 的 `data:` 图片，SVG 不进入工作台 DOM。代码块还在流式输出时显示占位，完成后绘制。头部是语言标签和图标按钮：预览与源码切换、复制源码、下载（SVG 或按 2 倍栅格化的 PNG）；图片点开进入 Files 的大图查看器。绘制失败时显示源码和失败原因，并提供"请模型修复"：把原因和源码作为一条用户消息发给本会话（运行中为排队的 follow-up），不自动改写回复。
2. **保存图片。** 新增 IPC `saveImage`：页面交出字节，主进程核对是 SVG 或 PNG、不超过 16 MiB、文件名只有一段，然后只写到用户在原生保存对话框里选的位置（先写临时文件再改名）。页面不能不经用户写文件，也不能决定位置。
3. **图片。** 回复里引用的本地图片若在会话的项目内，经 Files 的短期本地预览地址（`projectFilePreview(..., 'media')`，Core 校验路径，ADR-0076）内联显示，点开放大；项目外或读不到时显示为文件链接。远程图片不加载，显示为带主机名的卡片，点击经主进程原生确认在浏览器打开（渲染进程仍不访问网络，CSP 不变）。Read 读取的图片文件显示在该调用的行下方。MCP 等工具返回的图片字节目前不随条目传给界面，留作后续。
4. **消息时间。** AHP 的 `HistoryItem` 增加可选的 `at`（条目写入时间，Unix 毫秒），Agent Host 从 Pi 会话条目的时间填入；实时条目用 Core 事件的时间。用户消息和每个回合最后一条回复的操作行显示相对时间（一分钟内为"刚刚"，全部消息共用一个每分钟刷新的时钟），提示框是完整的日期与时间。新增字段只做展示，不改变既有语义。
5. **命令芯片。** 在输入框里选中的命令、skill 成为原子芯片（强调色名字，前面是半透明的 `/`，描述作为提示），发送时仍是 `/名称` 文本。`/` 在空输入框里直接唤起面板；在句中，`/` 位于词首且后面输入了名字字符时唤起，内置命令只在开头提供。Core 只展开位于开头的命令（T37 不变），句中的芯片是给模型的文字。面板的每一项以描述作为提示。

## 不采用

- 在页面里加载远程图片或经 Core 代理：会新增出网路径，并有模型输出借图片 URL 外带数据的风险，属于放松安全基线，需要另行决策。
- 把 Mermaid 的 SVG 内联进 DOM 并清洗：现有的隔离文档只回传图片，安全边界更简单。
