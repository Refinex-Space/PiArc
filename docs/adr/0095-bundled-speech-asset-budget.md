# 0095. 内置语音资产单列预算

- 状态：已接受（用户 2026-11-26 确认）
- 日期：2026-11-26
- 取代：无
- 相关：架构文档第 11 章；ADR-0094；[语音输入设计增补](../architecture/addenda/voice-dictation.md) 3.10 节

## 背景

第 11 章的预算：安装包 ≤ 200 MB（T44 基线 176.2 MB），安装后 ≤ 450 MB（基线 446.6 MB）。语音输入要求正常安装后断网即可使用，基础模型与运行时必须内置：X-ASR 权重 169 MB、Silero VAD 0.6 MB、sherpa-onnx 与 ONNX Runtime 动态库（macOS arm64 约 32 MB）。任何一种内置方式都会超出现有两行预算。需求原文要求"现有更严格约束优先"，同时要求内置。

## 决策

1. 第 11 章原有的安装包与安装后预算不变，判定时扣除 `Resources/speech/`（Windows 为安装目录下的 `resources/speech/`）。
2. 新增一行"内置语音资产"：安装后 ≤ 230 MB；对安装包（macOS arm64 DMG、Windows x64 安装包）的增量 ≤ 190 MB，以同一提交有无语音资产的两次出包之差计。
3. 增强模型（Qwen3-ASR）不内置，不计入以上任何一行；下载后的磁盘占用在设置页显示。
4. `scripts/perf/metrics.mjs` 的体积探针分别输出非语音部分与语音资产部分，`metrics.test.mjs` 要求新行有指标。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 直接上调总预算 | 一行判定 | 语音体积会掩盖其他部分的增长 | 不采用 |
| 不内置，首次使用时显式下载 | 预算不变 | 违反"安装后断网可用" | 不采用 |
| 单列语音资产预算 | 非语音部分照旧受约束，语音部分有自己的上限 | 两个数要分开测 | 采用 |

## 后果

- 正面：非语音部分的回归照样被拦住；语音资产超限单独暴露。
- 负面与代价：安装包实际变大约 150–190 MB；体积探针要识别语音目录。
- 需要配套做的事：架构第 11 章加一行与修订记录；体积探针与基线。

## 重新评估的触发条件

- 换基础模型或运行时导致语音资产超过本行预算。
- 语音输入改为可选组件或按需安装。
