# 0075. 会话工具在右侧独立分块

- 状态：提议
- 日期：2026-11-24
- 涉及：架构第 8.1、8.2、8.3 节，ADR-0029、0051、0070、0073

## 用户路径与布局

打开会话时，主块包含标题、会话工具按钮、消息和输入器。Session Rail 属于主块，在正文右边显示环境、上下文和实际可用的会话信息。终端、改动、后台任务、计划和侧边对话使用主块外侧的工具工作区。打开一个工具时主会话保留全高，工具拥有自己的标题和内容区。工具按钮分别反映各自的打开状态。

参考版本为 OpenClaudeDesktop `next-4.16336.0`。实机同时打开文件、侧边对话、预览、终端与改动时有多条独立分隔线。文件和侧边对话上下排列、预览与终端可以组成另一列。最大化 Files 时左导航保留，恢复后回到原布局；Changes 弹出成为单独系统窗口，可置顶或回到主窗口。关闭该工具后，邻块占用空出的空间。空白侧聊保留输入器，预览的新标签保留导航位置，文件树可单独调整宽度。PiArc 使用自己的会话、任务和检查点数据。新会话尚无会话终端时，终端操作遵守现有创建与归属规则。

## 实现依据

| 参考源码（位于该版本的 app/src） | 可观察行为及采用方式 |
|---|---|
| `tile-layout-model.mjs`、`tile-layout-store.mjs` | 首个终端默认主块与工具权重 2∶1，首个改动、文件和预览为 2∶3。实际尺寸还受最小宽度与上次调整影响。新增工具遇到最右单块时优先叠在其下，已有纵向分组时向右新增一列。保存每会话的布局和比例。 |
| `tile-drop-zones.mjs`、`source-tile-layout.jsx` | 移动有启动距离和可视落点。标题拖动可重排或新建横纵分割，取消时恢复。分隔条可拖动，双击均分；键盘可调整比例，移动把手允许按键预览分割及确认或取消。 |
| `source-terminal-pane.jsx`、`source-terminal-pane.css` | 标题行负责标签、新建和菜单，正文提供终端空间。PiArc 保留 libghostty-vt、现有终端输入归属、选择、查找、共享与停止拉帧逻辑。 |
| `source-side-chat.jsx`、`source-chat-side-chat.jsx`、`source-session-rail.jsx` | 侧聊输入器位于底边，空状态居中，详情分区独立滚动。PiArc 的侧聊沿用内存会话，只向父会话记用量。 |

## 生命周期和窗口边界

布局调整是呈现操作。移动、调整大小、最大化或恢复时需要保留同一侧聊标识、草稿与在途请求；每个终端只使用已有的 Core 终端任务。关闭终端视图后可重新连接，只有终端自身的结束操作才终止 shell。关闭侧聊、离开所属会话或退出应用时按 ADR-0070 清理。

独立窗口涉及页面归属。现有 `openSessionWindow` 创建完整工作台，侧聊随原组件卸载清理。建议为工具窗口建立由主进程验证的会话及面板绑定，按同一逻辑面板交接，回停靠后继续显示原内容；终端写入继续要求当前窗口近期真实输入。窗口异常退出时有且仅有一个负责清理的所有者。若本期选择窗口内分块，则只提供已接通的窗口内动作。

## 验收

- 同时打开详情栏、终端、改动；首个工具在右侧，后两个工具可上下并列，输入器随主块横向收窄。
- 调整列宽和行高，拖动改换位置，取消拖动，最大化再恢复，逐个关闭，切换会话和重载。验证窄窗、键盘焦点、减少动效、明暗主题与长标题。
- 终端输入、选择、共享与进程归属；侧聊提问、停止、草稿与清理；改动查看与评论；后台任务停止及分段输出全部通过原业务入口。
- 预览和文件支持独立开关、布局操作和明确的占位状态。本期以这两块的面板外壳为验收范围。
