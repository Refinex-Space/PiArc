# 0073. 设置页分段控件的视觉参考范围

- 状态：提议
- 日期：2026-11-24
- 拟修订：ADR-0006 中关于 Claude Desktop 视觉对标的范围，仅涉及设置页的分段控件
- 相关：ADR-0029，架构第 8.6、8.7 节

## 背景

外观设置与沙箱设置分别组装原生单选组。现有轨道使用实线边框，选中项用没有偏移和模糊的 1 px 阴影勾边。用户希望控件的比例、浅色轨道和轻微浮起的选中面与所附图二一致，并指定 OpenClaudeDesktop 的 next-4.16336.0 版本。ADR-0006 已否决将 Claude Desktop 的视觉复刻作为目标，项目参考规范还明确限制使用参考仓库的界面组件。

## 提议

将图二红框内的分段控件作为此次设置页改动的唯一视觉样本。通过对照参考版本的渲染结果，记录轨道与选中面的高度、圆角、内距、文本基线、背景和边缘。PiArc 在自身设计令牌与 React 组件中独立实现这些可观察特征，沿用原生单选语义、受控值、托管禁用和设置持久化。参考仓库的生成组件和样式代码仍受项目 clean-room 规则约束。

验收时以相同标签、主题、缩放和视口对照控件截图，再用 PiArc 的中文标签实测。图二只展示浅色静态选中态；键盘焦点、强制颜色、深色和减少动效按 PiArc 的既有约定验证。

## 重新评估的触发条件

拟把视觉对齐扩大到其他组件、设置页整体或品牌识别时，重新评估 ADR-0006 的范围。
