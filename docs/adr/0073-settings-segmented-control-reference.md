# 0073. 桌面前端对标 Claude Desktop，首项为设置分段控件

- 状态：已接受（composer 的运行位置托盘由 [ADR-0100](0100-two-tier-composer-and-context-tray.md) 修订；窗口区域划分由 [ADR-0105](0105-workbench-as-a-card.md) 修订）
- 日期：2026-11-24
- 修订：ADR-0006 第 3、4 条及其「复刻 Claude Desktop 视觉」备选结论的前端范围
- 相关：ADR-0029，架构第 8.6、8.7 节

## 决策

Claude Desktop 的视觉、UI 细节与交互是 PiArc 桌面前端的长期基准。前端可逐项复刻可观察的外观和行为，或高度参考后适配。每次改动明确参考版本、界面状态与验收范围，将布局、排版、表面、动效和交互规格映射为 PiArc 的设计令牌与可复用组件。当前参考版本为 OpenClaudeDesktop `next-4.16336.0`。

PiArc 独立编写组件、样式、文案和测试，使用自己的产品标识及品牌资产。Core、Agent Host、基于 Pi SDK 的 Harness、权限裁决、凭据与持久化继续遵循 PiArc 的架构和协议。研读参考源码用于查明控件及状态的设计依据；参考仓库中的生成组件、专有源码和资产仍受 ADR-0006 的使用约束。高度相似的整体外观仍有 ADR-0006 记录的产品识别风险。

## 第一项验收

设置页分段控件对照指定版本的 Default transcript view。设置行经过 `app/src/generated/settings-pages-v4/code-appearance.mjs`、`settings-rows.mjs` 使用 CDS 的 contained 分段控件。以同主题、同标签的渲染结果校准轨道、选中面、文字基线和间距。中文、深色、禁用、键盘、强制颜色和减少动效在 PiArc 内实际验证。选项值和保存结果继续由现有设置接口提供。

该版本的实测值为 CSS 像素。舒适模式轨道高 28、圆角 8、标签水平内距 12、字号/行高 14/20；紧凑模式分别为 24、6、8、13/19。两档均内收 1 px，选中面圆角比轨道小 1 px，选项宽度由文本决定。浅色轨道为约 5% 深色叠层，选中面白色；深色轨道和选中面分别叠加约 5% 和 10% 白色。PiArc 用系统字体显示标签，并采用自身的 120 ms 快速动效与减少动效设置。

## 重新评估的触发条件

参考版本、品牌资产使用、平台可访问性要求或 PiArc 的交互语义发生变化时，复核受影响的规格。涉及 Core 或 Harness 的行为变更按相应架构决策审议。
