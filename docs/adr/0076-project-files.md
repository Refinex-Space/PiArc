# 0076. 会话项目文件与本地文档预览

- 状态：已接受（用户委托选择 HTML 预览策略）
- 涉及：架构第 8.2、10.3 节，ADR-0022、0030、0036、0075

## 工作区

Files 的目录和文件名均以所属会话的工作树为根。目录按需加载，文件名和正文搜索有结果预算、取消与过期结果检查。用户保存文本时，Core 按原编码和换行写回，先核对打开时的版本。缺失文件只在显式创建时落盘。系统操作经主进程和本地输入授权。加入对话产生当前草稿中的文件提及或带行号的选区，由用户发送。

## 预览边界

参考版可在独立文档中运行 HTML 项目的脚本，加载相对资源，也允许部分 HTTPS 子资源。PiArc 的生产工作台只执行应用自身脚本，原生工具窗口只负责呈现。HTML 首次打开使用静态沙箱；只有受信任项目中的用户主动选择运行，才启用 HTML 脚本。为当前文件建立独立的临时沙箱文档，预览只加载已获准工作树内的资源，禁用外网、表单、弹窗、父窗口访问与应用 IPC。用户选择文件源代码或静态预览时不需执行项目脚本。静态模式显示正文结构和本地样式、图片。音视频与 PDF 由限制类型、生命周期和会话范围的本地阅读能力展示。

只读图片、音视频和 PDF 使用主进程签发的文档地址；同一文件的分段请求以文件身份、修改时间和尺寸绑定，按需从 Core 读取。HTML 子文档和工作台拥有不同来源。Chromium 内置 PDF 阅读器生成的文档子帧要求阅读器自身发起、父框架为内置阅读器、当前窗口持有活跃 PDF 授权。关闭文档或销毁页面时回收授权。

## 参考依据

OpenClaudeDesktop `next-4.16336.0` 的 `source-session.jsx`、`file-context-menu-model.mjs`、`source-files-search.jsx`、`source-file-viewer.jsx`、`source-file-editor.jsx` 及 `file-preview-frame.cjs` 给出了用户路径、文档模式、搜索和预览边界。桌面实操核对了 Markdown 表格、临时标签、可调文件树、文件行菜单、设置菜单、搜索入口与关闭恢复。实现使用 PiArc 自有组件、令牌、进程边界和文件服务。
