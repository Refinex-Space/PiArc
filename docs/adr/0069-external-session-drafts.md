# 0069. 快捷指令可以定位到带草稿的新会话

- 状态：已接受（2026-11-23，用户委托本次 T49 会话裁决）
- 涉及：T49-A09、A10，修订 ADR-0052 第 10 条

## 背景

ADR-0052 限制外部链接只能定位工作区或会话。T49 要求用户在快捷指令中填写文字，进入 PiArc 后仍能检查和修改。已有的工作区链接会忽略额外参数，改变它的行为会让原先无效的文字在升级后生效。

## 决策

为新会话单独注册 `piarc://draft?path=<本地绝对路径>&text=<草稿>`。路径沿用工作区链接的校验与信任流程。文字可省略，解码后最多 4096 个 UTF-16 代码单元，超限则拒绝。它只进入新会话的可编辑输入框，用户手动发送后才提交。已有 `open` 和 `session` 链接保持原有语义。

外部文字一律作为纯文本处理。接收链接时不执行命令、不展开斜杠命令、不调用模型、不替换当前会话的未发送草稿。Windows 跳转列表的任务复用同一应用内导航逻辑。
