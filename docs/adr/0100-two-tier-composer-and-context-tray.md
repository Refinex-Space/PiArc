# 0100. 两层输入卡片与上方的运行位置托盘

- 状态：已接受（用户在 2026-11-27 的会话中选定）
- 日期：2026-11-27
- 修订：ADR-0073 的前端基准在 composer 一项上的范围
- 相关：架构文档第 8.2 节；ADR-0030（composer 输入协议）、ADR-0052（worktree）、ADR-0094（语音输入）、ADR-0099（新会话页的工具）

## 背景

输入卡片原来采用参考版 Code 工作台的单行卡片（OpenClaudeDesktop `next-4.16336.0` 的 `singleRowCard`，"presets" 布局）。卡片只有一行，高 46 px，`+`、编辑区、麦克风和发送键排在同一行。卡片下方另有一条环境栏：新会话页列出运行位置、文件夹、模型、推理强度和权限模式，会话页列出 worktree、模型、推理强度、权限模式、自动审查状态、沙箱状态和用量环。这样的布局有三个问题：

- 占位文字和控件挤在一行，输入换行时卡片高度跳变。
- 环境栏控件是灰色小字，看起来像标签，不像按钮。"在哪里运行"（运行位置、文件夹）和"怎样运行"（模型、模式）也混在同一行。
- 新会话页中间还有一张两行环境卡，与环境栏重复列出文件夹和运行位置。

参考版还有 "classic" 布局：编辑区在上，操作行在卡片内（`ChatComposerParts.Actions` 与 `Chin`）。ChatGPT 桌面端用同一种两层卡片，并把运行位置（此计算机、项目、更多设置）放进卡片上方一条灰底托盘，托盘内收并压在卡片顶边之下。

## 决策

1. 输入卡片分两层。上层是编辑区，至少两行文字高；下层是卡片内的操作行：`+`、权限模式及其状态（自动审查、沙箱）在左，模型与推理强度、用量环在右，最后是麦克风和发送键。舒适密度下空卡片高 102 px，紧凑密度下 96 px。附件货架和听写条依旧位于编辑区上方。
2. 模型名用主文字色，推理强度紧跟其后，用次要文字色，读起来是一个标签，但两者仍是两个按钮，保留各自的快捷键（Mod+Shift+I、Mod+Shift+E）。危险模式（跳过权限）用警告色，最高推理强度用强调色。发送键在可发送时是唯一的实心控件。
3. 运行位置放进卡片上方的托盘（`Composer` 的 `tray` 插槽）。新会话页的托盘列出运行位置（本机或 worktree）和文件夹。选择 worktree 后，托盘第二行显示 worktree 名称和基础分支，由运行位置菜单开关，不再另设复选框。会话页只在会话属于 worktree 时显示托盘，内容是 worktree 名和分支。
4. 删除新会话页中间的环境卡和卡片下方的环境栏，它们的控件都移进托盘或操作行。测试标识（`home-environment`、`home-workspace`、`home-model`、`home-mode`、`session-model`、`session-effort`、`permission-mode`、`env-worktree` 等）保持不变。
5. 尺寸、颜色和间距仍只取设计令牌：输入卡片圆角 `workbench.composerRadius` 由 14 px 改为 18 px，托盘的内收、底边重叠和填充都由现有令牌计算。

托盘是 ChatGPT 的做法，参考版没有。本 ADR 只把 composer 的运行位置托盘移出 ADR-0073 的逐项复刻范围；两层卡片、操作行和菜单仍对照参考版的 classic 布局。

## 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 两层卡片，运行位置托盘在卡片上方 | "在哪里运行"和"怎样运行"分成两处；新会话页不再重复；卡片更高，多行输入不跳变 | 托盘超出 ADR-0073 的基准，要单独记录 | 采用 |
| 两层卡片，运行位置留在卡片下方（参考版 classic 的 chin） | 完全在 ADR-0073 的基准之内 | 运行位置仍排在卡片之下，和操作行的控件挨在一起，层次弱 | 不采用 |
| 保持单行，只加高并加大间距 | 改动最小 | 控件依旧分散，环境卡依旧重复 | 不采用 |

## 后果

- 正面：输入区域更高、更稳定；控件按用途分组，看得出能点；新会话页少了一张重复的卡片。
- 负面与代价：新会话页中间留白；托盘加 worktree 字段后高度随之增加。
- 需要配套做的事：架构第 8.2 节改写"新建会话"和"环境栏"两段；`workbench-layout` L4 改为检查两层卡片的几何关系；`t35-worktrees` 改为检查 worktree 字段出现。

## 重新评估的触发条件

出现以下任一情况时复核本决策：

- ADR-0073 的参考版本更新，并且新版 Code 工作台的输入卡片或运行位置的布局有变化。
- 新会话页增加新的运行位置（例如远程环境），托盘放不下。
- 窄窗口（宽度 560 px 以下）的操作行放不下模式、模型和用量环。
