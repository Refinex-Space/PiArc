# 0074. 设置在发起操作的工作台内打开

- 状态：已接受
- 日期：2026-11-24
- 修订：架构第 8.2 节的独立设置窗口
- 相关：ADR-0029、ADR-0073

## 决策

设置是工作台内的模态面板。齿轮、快捷键、应用菜单与功能页的定位入口在发起操作的窗口打开设置。背景工作台保留会话和编辑状态，模态期间隔离其输入，关闭后恢复焦点。多个主窗口按各自的设置路由呈现。设置数据、托管锁和需要原生确认的操作仍由已有主进程与 Core 接口处理。

## 依据与验收

指定参考版本的设置具有遮罩、共用标题栏、搜索导航和独立滚动的内容区。复查实机后选择工作台内模态；独立系统窗口会把窗口切换、输入隔离和焦点归还交给不同的宿主。页面由 PiArc 实际注册的分类生成，语言、主题、选择器及用量按 PiArc 的数据和持久化接口适配。用真实开关、快捷键、深链定位和明暗主题截图验收。

## 重新评估的触发条件

需要同时操作设置与背后的同一工作台，或平台原生窗口交互要求发生变化时复核。
