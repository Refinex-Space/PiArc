# 0078. 会话主块对标 Claude Desktop 的 Code 会话

- 状态：已接受（补充）
- 日期：2026-11-25
- 相关：ADR-0006、0022、0029、0030、0061、0073、0075；架构第 8.4–8.7 节

## 决策

会话主块（标题行、对话区、审批卡与输入区）以 OpenClaudeDesktop `next-4.16336.0` 呈现的 Claude Desktop Code 会话为视觉与交互基准。逐项规格、PiArc 现状与处理方式见 [会话主块对标差异表](../research/session-pane-fidelity.md)。Core、Agent Host、Pi Harness 与 AHP/Core API 的语义不变，界面只呈现 PiArc 已有的数据和能力。

1. **参考值的取法。** 参考应用以 `comfortable` 密度和 `fizzy-lake` 的 color、panels、type 三项运行，规格按这个组合换算。参考的 compact 档对应 PiArc 紧凑密度。参考的对话字号跟随"聊天文字大小"，PiArc 舒适档取默认档 15/21，紧凑档取小号 14/20；简体中文正文行高分别为 24 和 22。
2. **令牌。** 新的尺寸、间距、圆角、字阶与动效写进 `design/tokens/` 的会话组，组件只读令牌。颜色只补三个层级：淡底（约 5%）、淡底悬停（约 10%）和细线（约 8%），色相仍是 PiArc 的色板。主按钮沿用 PiArc 的强调色，参考的近黑主按钮不采用。
3. **图标。** 全应用只从 `shell/icons.tsx` 取用，线框图标一律是 lucide-react（ISC，精确锁定 1.66.0）的字形，经同一个 `glyph()` 固定尺寸和线宽：12 px 线宽 1，16 px 与 20 px 线宽 1.25（工具栏可在 CSS 里收到 1）。原先手绘的 16 px 线框图标保留导出名、改由 Lucide 绘制；只有 Lucide 没有的实心形状（侧栏标记、项目展开三角、停止方块、完成圆、转圈、步骤箭头）在同一文件自绘。
4. **working 标记。** 不使用参考的火花标记和精灵图（ADR-0006，`ui-reference-notes.md` 第 9 节）。PiArc 自有标记由品牌字形 P、i 的 10 个方块组成，按笔画顺序依次点亮。思考节奏慢，执行工具快，等待审批时静止并以警告色呼吸。尺寸、悬挂位置与进出场时长取参考值。标记只用 CSS 动画，减少动效时静止。
5. **独立实现。** 参考的数值、状态逻辑与文案结构用于确定规格。组件、样式和文案由 PiArc 编写，不复制 `app/src/generated/` 下从官方应用切出的代码。
6. **不变量优先。** 参考与以下不变量冲突时保留 PiArc 的做法，并在差异表中写明：
   - transcript 的虚拟列表、按行订阅与 `STREAMING`、`SCROLL_FOLLOW` 常量；
   - Markdown worker、shiki JavaScript 正则引擎、CSP 与 `feed`/`article` 语义；
   - 审批的 400 ms 防误触、长参数阅读闸门、输入法守卫、首张可见卡响应；
   - allow 规则与沙箱放宽一律经原生确认；
   - 生成中的思考块强制展开（已由 ADR-0079 取代：思考默认折叠，并入相邻工具组）。
   新回复入场只做淡入和小位移，不做整块弹簧，避免流式中的位移。

## 不采用

- 参考有、PiArc 没有对应能力的界面（听写、Bash 模式、历史检索、工作流卡、提案、评审发现、回复反馈与章节、回合末撤销卡、选区浮条）不做空壳，差异表记为不适用。
- 标题行按钮折叠为"View options"：PiArc 窄窗由 ADR-0075 的分块布局处理。

## 重新评估的触发条件

参考版本更新；PiArc 增加听写、工作流或回合级撤销等能力；平台可访问性要求变化；lucide-react 需要升级大版本。
