## 背景与目标

到 T17 为止，Core 与 Agent Host 已经能跑完整的会话，但应用窗口还是 T03 的占位骨架。本任务做出用户第一眼看到的客户端：设计令牌、窗口骨架、按工作区分组的会话列表、新建会话流程、首次进入工作区的信任对话框，以及之后所有界面共用的基础设施（store、设置窗口、快捷键、通知、i18n）。

视觉必须是 PiArc 自己的品牌，与 Claude 明确区分（ADR-0006、架构第 8.6 节）。D3 已给出时按 D3 实现；没给出时用中性的临时令牌，并在视觉关口请用户确认。

完成后，用户可以打开文件夹、通过信任对话框、新建并管理会话；T19 在此基础上接入 transcript 与 composer。

## 交付物

### 1. 设计令牌

- `design/tokens/*.json` 按第 8.6 节分层（原始色板 → 明暗阶梯 → 语义层 → 组件层），脚本生成 CSS 自定义属性与 TS 常量；生成产物漂移检查并入 verify。
- 四种模式（明、暗、明高对比度、暗高对比度）× 两档密度；跟随 `prefers-color-scheme`、`prefers-contrast`、`forced-colors`，设置中可覆盖。
- 对比度检查并入 verify：按声明的前景 / 背景对检查 WCAG AA（正文 4.5:1，大字与界面组件 3:1），高对比度模式正文 7:1。
- 品牌检查：主色色相不落在橙色 / 陶土色范围（范围写进检查脚本）；不使用 Anthropic 的字体、图标、提示音（第 8.6 节、`ui-reference-notes.md` 第 9 节）。字体用系统字体。

### 2. 窗口骨架

- 三栏（侧栏、会话主区、右栏）+ 可停靠面板区。面板区与右栏是注册式容器：本任务提供布局、停靠、尺寸记忆，没有注册内容时不显示空壳。
- macOS：隐藏式标题栏保留红绿灯，侧栏使用 vibrancy；Windows：Mica 背景与标题栏覆盖层。正文区域用不透明背景。
- 侧栏宽度 200–420 px，可折叠。

### 3. 会话列表与新建会话

- 侧栏按工作区分组；状态徽标优先级：错误 > 等待审批 > 运行中 > 未读 > 空闲（状态来自 Core 的会话快照）。
- 过滤、置顶、归档、重命名、删除（删除前确认，同时删除 Pi JSONL 与会话临时目录，第 9.3 节）。这些操作的 Core 命令在本任务中实现。
- 新建会话：先显示乐观的用户消息（带 `clientId`）→ 创建会话 → 发送首条输入；失败时回滚并把输入内容放回输入框。
- 打开文件夹作为工作区（主进程系统对话框）；最近工作区列表。

### 4. 信任对话框

- 第一次在某个工作区创建会话前显示，列出 T13 枚举的可执行项（按类别与来源文件），并说明 memory 文件不受信任影响、会标注来源。
- 选项：信任 / 暂不信任（继续以受限方式使用）。决定写入 Core。
- 再次打开已信任的工作区时，若 T13 报告了新增的可执行项，只列出新增项请用户确认（第 10.2 节）。

### 5. store

- 基于 `useSyncExternalStore` 自写，按会话与 item 粒度订阅；流式增量只让最后一个 item 的订阅者重新渲染。
- 实体快照按 `revision` 门控；乐观回显按 `clientId` 对账替换。

### 6. 设置窗口、快捷键、通知、i18n

- 设置是独立窗口，分组导航由各任务注册页面；本任务注册"通用""外观""快捷键"三页。
- 快捷键注册表：命令 id → 默认按键（`Mod` 记法），用户覆盖存入用户级设置，修改后立即生效（含主进程菜单加速键）；检测冲突；本任务注册 Mod+N、Mod+W、Ctrl+Tab、Mod+/，其余快捷键由所属任务注册。
- 系统通知：会话完成或等待审批、且窗口不在前台时通知；按 S6 结论，ad-hoc 签名下不可用时退回应用内提醒 + Dock 弹跳。Dock 角标 / 任务栏覆盖图标显示需要处理的会话数（等待审批、出错、完成未读，定义集中在一处）。
- i18n：ICU MessageFormat，简体中文与英文两套资源，主进程菜单与渲染进程共用；本任务新增的界面字符串全部经过它；语言切换后界面与菜单立即更新。

### 7. 测试与证据

Playwright 驱动 Electron 跑本任务的全部流程；评审截图（亮、暗，两档密度）放在 `tmp/evidence/T18/`。

## 实现要点

- 渲染进程能调用的命令逐个加进 preload 白名单，主进程校验 `senderFrame` 的 origin（T03 的框架）。删除会话这类不可逆操作，确认放在主进程侧。
- 删除会话前先经 T14 关闭会话，让 Agent Host 停止写该文件，再删除 JSONL。ADR-0011 的"Core 只读"指不改写内容；删除整个会话按第 9.3 节执行。
- 组件只读语义层令牌；视觉方向被用户调整时，只改令牌，不改组件。
- 视觉关口放在最后：功能、测试、截图都完成后，看板状态改为"阻塞（等待用户确认视觉方向）"，报告中附截图路径与令牌摘要（主色、中性色阶、字体）。用户确认或给出修改意见后调整令牌、重新截图，再标 T18-A03 为 `passing`。
- 冷启动测量用打包产物，侧栏夹具为 100 个会话，打点从进程启动到侧栏数据渲染完成。

## 验收标准

- [T18-A01] 令牌生成 CSS 自定义属性与 TS 常量，四种模式 × 两档密度齐全；故意把一对前景 / 背景改到 AA 以下时 verify 失败，恢复后通过。验证：生成产物与两次 verify 的关键输出。
- [T18-A02] 品牌检查生效：故意把主色改为橙色色相时检查失败；界面不含 Anthropic 的字体、图标与提示音。验证：检查脚本输出与资源清单。
- [T18-A03] 用户已确认视觉方向。验证：亮暗评审截图（`tmp/evidence/T18/`）与用户在会话中的确认。
- [T18-A04] macOS 上隐藏式标题栏与侧栏 vibrancy 生效；Windows 上应用能启动并加载 Mica 配置。验证：macOS 截图与 Windows CI 冒烟输出（实机外观在 W1）。
- [T18-A05] 侧栏徽标按"错误 > 等待审批 > 运行中 > 未读 > 空闲"取最高优先级。验证：单测与截图。
- [T18-A06] 过滤、置顶、归档、重命名、删除会话可用；删除后 Pi JSONL 与会话临时目录被移除，重启应用后结果保持。验证：Playwright 流程与文件检查。
- [T18-A07] 新建会话时乐观消息立即出现；注入创建失败后消息回滚，输入框保留原内容。验证：Playwright 流程（故障注入）。
- [T18-A08] 信任对话框按类别列出夹具工作区的全部可执行项；选择暂不信任后，夹具 `.pi/extensions/` 注册的工具不出现在模型请求中；信任后出现；新增一个可执行项后再次打开只列出该项。验证：Playwright 端到端与 mock provider 请求断言。
- [T18-A09] 流式增量只触发最后一个 item 订阅者的渲染；旧 revision 快照被丢弃；乐观回显被 Core 确认替换且不重复。验证：store 单测（含渲染计数）。
- [T18-A10] 在设置中修改 Mod+N 后新按键立即生效、旧按键失效，主进程菜单显示新按键；与已有快捷键冲突时提示。验证：Playwright 流程。
- [T18-A11] 窗口不在前台时，会话完成触发系统通知（不可用时为应用内提醒与 Dock 弹跳），Dock 角标数字正确。验证：macOS 实测记录与截图（Windows 在 W1）。
- [T18-A12] 中英文切换后界面文字与主进程菜单立即更新。验证：Playwright 流程与截图。
- [T18-A13] 打包产物冷启动到侧栏（100 个会话）就绪不超过 1.0 s。验证：10 次测量的最大值。
- [T18-A14] `npm run verify` 通过。验证：命令输出。
