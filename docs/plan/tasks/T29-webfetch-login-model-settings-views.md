## 背景与目标

本任务收齐 M2 剩下的四块，彼此独立：

- **WebFetch**：本地抓取网页，转成 Markdown，再由辅助模型按提示提取。它是 agent 访问网络的入口，SSRF 防护与域名规则必须先于功能。
- **辅助模型调用通道**：WebFetch 的提取需要一次独立的模型调用，M5 的 Auto 模式也会用到，所以做成通用通道。
- **登录与每模型设置**：服务商的 OAuth 与设备码登录（Anthropic 订阅方式仍然屏蔽，ADR-0006），以及每个模型的显示名、上下文窗口、图片输入、默认 effort。
- **三档视图**：transcript 的普通、思考、详细三档。

完成后，M2 的功能范围（第 16 章）全部就位，T30 可以开始做行为对齐。

## 交付物

### 1. WebFetch

- 流程：抓取 URL → HTML 转 Markdown → 辅助模型按调用参数中的提示提取 → 工具结果。提取用的提示词自写。
- 执行位置：沿用 ADR-0004 第 3 条"工具 I/O 下沉 Core"的思路，网络抓取放在 Core（新增 AHP 方法，补充型决策，写进第 7.4 节），SSRF 检查、上限与审计都在实际发起连接的一侧完成。若选择放在 Agent Host，写明理由并保证同样的检查。
- 权限：Manual 下默认询问；`WebFetch(domain:…)` 规则由 T23 的匹配实现，本任务接入工具；"总是允许"按域名生成规则。
- 上限：响应体大小、转换后正文长度（官方参考值为 100K 字符）、总超时，集中定义可配置；超限时截断或中止并给出明确错误。
- 重定向：同域跟随；跨域重定向不自动跟随，把目标地址返回给模型，由它重新发起（会再走一次权限裁决）。
- SSRF 防护：域名解析后对每个目标 IP 检查，拒绝回环、私有网段、链路本地、组播、未指定地址及其 IPv6 等价形式（含 IPv4 映射地址）；连接到已检查的 IP，防止 DNS 重绑定；每次重定向重新检查；允许列表可配置（测试服务器靠它放行）。

### 2. 辅助模型调用通道

- Agent Host 中的通用函数：给定提示与输入，用配置的辅助模型完成一次无工具调用，返回文本与用量；用量计入会话。
- 设置项"辅助模型"（服务商 + 模型）；未设置时使用当前会话模型。T31 引入别名后可指向别名。

### 3. OAuth 与设备码登录

- `ModelRuntime.login` 的 `interaction` 回调（授权 URL、设备码、输入提示）经 AHP `ui/loginInteraction` 到客户端；授权页用系统浏览器打开（经主进程的外链确认），不在应用窗口内加载第三方页面；回调走本地回环端口。
- token 只进凭据保险箱。登录取消、超时、回调错误都有明确提示。
- 可用登录方式列表继续排除 Anthropic 订阅 OAuth；T21 的 CI 测试覆盖新增的登录界面路径。
- 设置窗口"模型与服务商"页增加登录与登出操作。

### 4. 每模型设置

- 显示名、上下文窗口、图片输入、默认 effort，覆盖 T21 能力表中的对应值。
- 生效点：上下文窗口影响 T27 的压缩阈值与用量环；图片输入影响附件是否被接受；默认 effort 在选中该模型时应用。

### 4b. 低可靠性模型的保守 Tool Profile

- 架构第 6.13 节：能力表中工具调用可靠性等级为"低"的模型，使用更保守的 Tool Profile：工具更少（按 Profile 定义的子集）、描述更明确、默认启用任务清单提醒。Profile 只改变模型看到的工具名、描述与工具子集，权限规则与 hooks 仍按规范名匹配（第 6.1.1 节）。
- 用户可在每模型设置中改用默认 Profile。

### 5. 三档视图

- 普通：工具折叠为摘要；思考：在普通基础上显示思考摘要；详细：全部展开，包括 T27 标记的 reminder item。
- 切换入口放在 transcript 顶部或视图菜单，按会话记忆（呈现状态，存渲染进程）。

### 6. L2 场景与能力 ID

场景放在 `tests/scenarios/webfetch-*.yaml`，能力 ID 形如 `CAP-WEB-FETCH-001`、`CAP-MODEL-SETTINGS-001`。WebFetch 场景用本地测试 HTTP 服务器（经允许列表放行），不访问外网。

## 实现要点

- 模型输出与网页内容都是不可信数据：提取结果作为工具结果返回，不进入 system prompt；网页中的指令不改变权限裁决（第 10.1 节）。
- mock 授权服务器放在 piarc-testkit，覆盖授权码与设备码两种流程，以及拒绝授权、过期两种错误。
- SSRF 检查写成纯函数（输入解析后的地址列表与配置），用表驱动单测覆盖每个网段。
