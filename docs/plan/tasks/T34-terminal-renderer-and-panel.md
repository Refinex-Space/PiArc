## 背景与目标

按 ADR-0017，渲染进程不解析 VT：它按 `requestAnimationFrame` 节奏向 Core 拉取增量帧并用 Canvas 绘制，键盘、鼠标、粘贴事件原样发回 Core 编码。T10 fork 了 ghostty-web 的 `CanvasRenderer` 做原型，T33 定稿了帧协议、输入编码与读屏。本任务交付正式渲染器与终端面板。

开工第一步：读 S7 报告的路线结论，把选定的路线写进 `PLAN.md` 检查点。

- **主路线**：fork 的 Canvas 渲染器，由帧协议驱动。
- **退路**（S7 结论为启用 xterm.js 时）：渲染端改用 xterm.js 6 + WebGL 插件的字节流副本模式（ADR-0017 第 7 条），交付物第 1 节按退路实现；面板、IME、选区与复制、查找、链接、重载恢复、无障碍照做。

## 范围

### 要做

- Canvas 渲染器（或退路的 xterm.js 副本模式）。
- rAF 拉帧与隐藏时停止；键盘、鼠标、粘贴发回 Core。
- IME：隐藏 textarea 跟随光标、预编辑文本绘制。
- 选区（Core 侧选区手势 API 与界面）与复制；查找界面；链接（OSC 8 与 URL）打开前确认；基础无障碍。
- 终端面板：停靠、多标签、与会话共享 cwd、共享给 agent 的开关、选中内容附加到对话。
- 渲染进程重载后的恢复；fork 代码的许可证与来源记录。

### 不做

- Windows 上的 IME 实机核对与 ConPTY 实机表现（W3）。
- wterm DOM 渲染器（ADR-0017 中的备选），除非 S7 结论要求。
- 终端分屏、Kitty graphics。

## 交付物

### 1. 渲染器（主路线）

- 基于 T10 的 fork 实现由帧协议驱动的 `RemoteRenderable`：按行 id 复用已绘制的行、只重绘脏行、维护样式表增量；处理小数 DPR、宽字符、emoji 与 ZWJ 字素、powerline 字形（单元格宽度以 Core 给出的为准）。
- 光标样式与闪烁；遵循 `prefers-reduced-motion`。
- 字体用第 8.6 节的系统等宽字体；颜色取设计令牌与终端调色板。

### 1'. 渲染器（退路）

- xterm.js 6 + WebGL 插件接收 T33 的字节流副本；连接或重连时先应用 Core 的 VT 重放。
- xterm.js 产生的查询应答一律丢弃，只认 Core 的 `WRITE_PTY`。
- 在已知限制中写明：agent 与用户的屏幕由两个仿真器算出，字素簇与 reflow 等边角情况可能不一致。

### 2. 拉帧与输入

- 只在 rAF 回调中拉帧；面板折叠、标签不可见、窗口最小化或 `document.hidden` 时停止拉帧（退路：暂停字节流投递，恢复时经 VT 重放补齐）。
- 键盘、鼠标、粘贴、焦点事件交给 T33 的编码接口。终端获得焦点时，除快捷键注册表中标为全局的少数快捷键外，按键都交给终端（第 8.5 节）。
- 复制与中断：有选区时 Mod+C 复制；Windows 上 Ctrl+C 有选区时复制、无选区时发给终端。

### 3. IME

- 隐藏 textarea 跟随光标位置，候选框随之定位；预编辑文本在光标处绘制；`compositionend` 后把上屏文本一次写入 PTY。
- 合成期间的按键处理遵守第 8.5 节的输入法守卫。

### 4. 选区、查找与链接

- 选区：在 piarc-term 与 NAPI 中暴露 libghostty-vt 的选区手势 API；渲染端把指针事件交给它，选区由帧中的行内区间带回。支持拖选、双击选词、三击选行、Shift 扩展。
- 查找：查找栏调用 T33 的搜索接口，高亮匹配、上下跳转、显示匹配数。
- 链接：识别 OSC 8 超链接与普通 URL；点击后先显示目标地址，确认后经主进程用 `shell.openExternal` 打开，只放行 `https:`、`http:`、`mailto:`（第 10.3 节）。

### 5. 终端面板

- 可停靠面板，多标签；新标签以当前会话 cwd 启动；标签可重命名，标题跟随 `TITLE_CHANGED`；关闭标签终止 shell 进程树；Ctrl+反引号切换面板。
- 每个标签有"共享给 agent"开关（默认关闭），对应 T33 的共享状态；agent 启动的终端承载任务也可在面板中打开查看。
- 选中内容可附加到对话，在 composer 中以胶囊显示。

### 6. 重载恢复与无障碍

- 渲染进程重载或崩溃后重新订阅，一次拉帧恢复完整内容（退路：VT 重放），shell 进程不受影响。
- 基础无障碍：终端区域可聚焦、有可读标签；提供"以文本查看屏幕"入口，内容取自 Core 的读屏 API，供屏幕阅读器使用。

### 7. 许可证与来源

- fork 的代码保留 ghostty-web 的 MIT 版权声明与许可证文件；在代码注释与提交说明中记录来源（仓库、路径、版本）与改动。
- 登记到第三方许可证清单的来源文件中（T50 生成 `THIRD_PARTY_NOTICES` 时读取）。走退路时登记 xterm.js 与 WebGL 插件。

## 实现要点

- 渲染端不缓存终端业务状态，只缓存已绘制的行位图；一切以 Core 的帧为准。
- 拉帧开销与终端输出量无关，只与帧率和脏行数有关；测量时同时记录 IPC 字节数。
- Playwright 截图前等待帧稳定（帧序号不再变化），避免截到半帧。

## 验收标准

- [T34-A01] vim、htop、less 在面板中渲染正确，覆盖颜色、光标、alt screen 切换与窗口缩放后的重排。验证：Playwright 截图（存 `tmp/evidence/T34/`）与 Core formatter 输出对照。
- [T34-A02] 面板隐藏或窗口最小化时渲染进程不接收终端数据（主路线：拉帧次数为 0；退路：暂停字节流投递），恢复显示后内容完整。验证：测试（计数）。
- [T34-A03] 中文输入法的预编辑文本绘制在光标处，候选框跟随光标，上屏文本只写入 PTY 一次。验证：macOS 实测截图与组件测试（模拟 composition 事件）。
- [T34-A04] 键盘、鼠标、粘贴经 Core 编码：vim 中方向键、鼠标点击与 bracketed paste 生效。验证：Playwright。
- [T34-A05] 拖选、双击选词、三击选行后复制，剪贴板内容与屏幕文本一致。验证：Playwright。
- [T34-A06] 查找栏高亮全部匹配并可上下跳转，显示匹配数。验证：Playwright。
- [T34-A07] OSC 8 链接与普通 URL 点击后先显示目标地址，确认后才调用 `shell.openExternal`，取消则不打开。验证：Playwright（拦截主进程调用）。
- [T34-A08] 面板支持多标签，新标签以会话 cwd 启动，关闭标签终止 shell 进程树，Ctrl+反引号切换面板；选中内容可附加到对话。验证：Playwright。
- [T34-A09] "共享给 agent"开关默认关闭，打开后 agent 才能读取该终端。验证：Playwright 与 L2 场景。
- [T34-A10] 渲染进程重载后终端内容恢复、shell 进程不受影响（主路线：一次拉帧；退路：VT 重放，且渲染端产生的查询应答被丢弃）。验证：测试。
- [T34-A11] `cat` 100 MB 期间主进程事件循环延迟 p99 ≤ 16 ms，键入回显额外延迟 p95 ≤ 5 ms，并记录帧率与 IPC 字节数。验证：测量输出（与 S7 数据对照）。
- [T34-A12] 终端区域可聚焦、有可读标签，"以文本查看屏幕"的内容与读屏 API 一致。验证：axe 检查与 Playwright。
- [T34-A13] fork 代码保留 MIT 版权声明与许可证文件，来源与改动已记录，并登记到第三方许可证清单（退路时为 xterm.js）。验证：文件检查。
- [T34-A14] `npm run verify` 通过。验证：命令输出。
