## 背景与目标

M1–M4 的界面陆续完成，无障碍与本地化分散在各任务里，没有统一检查过。本任务做一次全面收口，并把能自动化的部分变成检查失败条件，防止后续回退：

- 语义化 HTML 与 ARIA：axe 自动化覆盖全部页面与组件状态，亮色与暗色零违规；
- 读屏体验：transcript 行描述、流式输出的节流播报、审批卡的焦点与播报（第 8.7 节）；
- 全键盘可达、焦点顺序、系统偏好（减少动态效果、高对比度、强制颜色）；
- 中英文全覆盖，缺失翻译检查并入 verify。

完成后，新增页面不登记 a11y 状态、或新增文案缺少翻译，verify 都会失败。

## 交付物

### 1. axe 自动化与状态清单

- 状态清单（入库）：每个页面与组件状态一条，至少覆盖每个设置页、每种 transcript 行类型、四类审批卡、计划卡与任务卡、子 agent 卡、Changes 面板（含行内评论）、终端面板、命令面板、信任对话框、插件启用确认、模型切换代价提示、空状态与错误状态。
- Playwright 逐条打开状态，用 axe 检查亮色与暗色两种模式；报告放在 `tmp/evidence/T43/`。发现的违规全部修复，不靠禁用规则通过。
- 覆盖检查：从路由与设置页注册表中枚举页面，与状态清单比对；有页面没登记时检查失败。

### 2. 读屏体验

- transcript 每种行类型提供可访问名称，例如"工具调用：编辑 3 个文件，成功"，经 i18n 输出。
- 流式输出：不逐字播报；`aria-live="polite"` 区域按节流间隔更新摘要，回合结束时播报一次结果。节流间隔作为常量集中定义。
- 审批卡出现时：焦点移到卡片容器（不是"允许"按钮），并播报卡片类型与对象；输入法合成期间推迟移动焦点；400 ms 防误触对键盘激活同样生效。

### 3. 键盘与系统偏好

- 所有功能可以只用键盘完成；焦点顺序按区域设计（侧栏 → 会话主区 → 右栏 → 面板）；焦点环始终可见；对话框内焦点受限，关闭后回到触发元素；终端获得焦点时保留离开终端的全局快捷键。
- `prefers-reduced-motion` 与应用内开关关闭动效；`prefers-contrast: more` 使用高对比度令牌；`forced-colors: active` 下使用系统颜色，状态信息不只靠颜色表达（同时有图标或文字）。

### 4. VoiceOver 核对清单

- 写入 `docs/engineering/accessibility.md`：无障碍规则摘要、状态清单的维护方式、读屏核对清单（VoiceOver、Narrator、NVDA 共用，每项一列结论）。
- 清单覆盖：会话列表与状态徽标、transcript 行描述、流式播报、四类审批卡、Changes 与评论、设置页、终端面板。
- 需要实际开启 VoiceOver 操作的项，请用户操作并把结果告诉你；用 AppleScript 控制 VoiceOver 需要修改系统设置，先征得用户同意。用户暂时无法操作时，对应验收项标 `blocked` 并写明原因。

### 5. 本地化

- 全部用户可见字符串（渲染进程、主进程菜单、通知、错误提示、可访问名称）走 ICU MessageFormat 资源，中英文两套。日期、数字、时长用 `Intl` 按当前语言格式化。
- 检查脚本 `scripts/ci/check-i18n.mjs`（跨平台）并入 verify：两种语言的键集合一致；代码引用的键都存在；ICU 语法有效且两种语言的占位符一致；渲染进程与主进程源码中没有硬编码的用户可见字符串（用 ESLint 规则或脚本扫描实现，新增依赖需说明理由）。
- 主要页面在中文与英文下各截一张图，检查截断与溢出。

## 实现要点

- 先跑一遍 axe 全量报告，按规则分组修复，避免逐页反复改同一个公共组件。
- 可访问名称与可见文案共用同一份 i18n 资源，不另写一套。
- 节流播报的测试用假时钟统计 live region 的更新次数，不依赖真实读屏软件。
- 修复中发现的缺陷先写失败测试再修。

## 验收标准

- [T43-A01] axe 在状态清单的全部条目上零违规，亮色与暗色各跑一遍；清单覆盖每个设置页、每种 transcript 行类型、四类审批卡与交付物 1 列出的对话框和面板。验证：Playwright + axe 报告（`tmp/evidence/T43/`）。
- [T43-A02] 新增页面未登记到状态清单时覆盖检查失败。验证：临时新增一个未登记页面时的失败输出，撤销后通过。
- [T43-A03] transcript 每种行类型都有可访问名称，中英文各自正确。验证：组件测试断言可访问名称。
- [T43-A04] 100 token/s 流式输出期间 live region 按节流间隔更新、不逐字更新，回合结束时播报一次结果。验证：测试（假时钟统计更新次数）。
- [T43-A05] 审批卡出现时焦点移到卡片容器并播报；输入法合成期间推迟移动焦点；卡片出现后 400 ms 内键盘激活无效。验证：Playwright。
- [T43-A06] 只用键盘完成新建会话、发送消息、处理四类审批卡、打开 Changes 并发表评论、修改一项设置、进入与离开终端面板；焦点顺序符合设计，焦点环始终可见，对话框关闭后焦点回到触发元素。验证：Playwright 键盘流程用例与截图。
- [T43-A07] `prefers-reduced-motion` 与应用内开关关闭动效；`prefers-contrast: more` 使用高对比度令牌；`forced-colors: active` 下使用系统颜色，状态信息不只靠颜色表达。验证：Playwright 媒体模拟用例与截图。
- [T43-A08] 两种语言键集合不一致、代码引用不存在的键、占位符不一致或出现硬编码的用户可见字符串时 verify 失败。验证：临时删除一个英文键、临时写入一个硬编码字符串时的失败输出，撤销后通过。
- [T43-A09] 主要页面在中文与英文下无截断与溢出。验证：两种语言的截图。
- [T43-A10] `docs/engineering/accessibility.md` 包含读屏核对清单，VoiceOver 一列逐项有结论，需要用户操作的项注明。验证：文件内容。
- [T43-A11] `npm run verify` 通过。验证：命令输出。
