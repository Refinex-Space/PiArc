## 背景与目标

M1 已在 macOS 上通过 R2 验收。按第 15.1 节，Windows 最迟在下一个里程碑结束前达到同样标准；本计划要求在 R3 之前完成。Windows CI 从 M0 起一直在跑 `npm run verify`，但 CI 证明不了真实安装、真实 shell、凭据管理器、输入法、系统通知与 Mica 外观这些只有实机才能确认的行为。

本任务在 Windows 11 实机上按 M1 退出标准逐条验收，修复平台问题，结论写入报告与 `PLAN.md`。W1 与 M2 的 macOS 任务交替执行：开工时主线可能已包含部分 M2 改动，验收范围仍是 M1。

## 范围

### 要做

- 在实机上构建、安装并运行 PiArc，按交付物 2 的检查表逐条验收。
- 修复 Windows 平台问题，或登记。
- 写 W1 报告，更新 `PLAN.md`。

### 不做

- M2 功能的 Windows 验收（W2）。验收中顺带发现的 M2 功能问题登记给 W2，除非它挡住了 M1 检查项。
- Windows 沙箱（T39）。
- 改动用户的系统安全设置（SmartScreen、智能应用控制等）。需要放行时按 W0 的步骤由用户操作。

## 交付物

### 1. 准备

- 开工检查确认 `process.platform` 为 `win32`；记录 Windows 版本、架构与当前提交号。
- 跑基线 `npm run verify`；用 T12 的流程构建 Velopack 安装包（或使用 CI 产物）并安装，首次运行的放行步骤由用户完成。

### 2. 检查表

| 检查项 | 做法 |
|---|---|
| 完整任务 | 用与 R2 相同的服务商组合与任务，完成"读代码 → 改代码 → 跑测试"；工作区放在含空格与中文的路径下。真实服务商调用前说明预计次数并征得同意 |
| L2 场景 | 本机运行全部 L2 场景（不只依赖 CI），数量 ≥ 20 |
| Git Bash | 探测成功时 `Bash` 工具经 Git Bash 执行；从 PATH 中隐藏 Git Bash 后出现安装提示，只提供 `PowerShell` 工具 |
| PowerShell | 工具可执行，Manual 下询问 |
| 路径 | 盘符、UNC、含空格与中文、超过 260 字符的长路径、保留文件名（`CON`、`NUL` 等）、大小写不敏感 |
| 换行与编码 | CRLF 文件经 Edit 保真；子进程输出中的中文不乱码 |
| 进程树 | 命令超时与停止时 Job Object 终止整棵进程树，`tasklist` 核对无残留 |
| 凭据与数据目录 | 主密钥在凭据管理器，重启后凭据可读；数据目录为 `%LOCALAPPDATA%\PiArc\`；数据目录与日志无明文凭据 |
| 输入法 | 微软拼音在 composer 与审批卡中：合成期间 Enter、Esc、`/`、`@` 不触发业务，候选上屏正确 |
| 通知与任务栏 | 窗口不在前台时，回合完成与等待审批弹出 Toast；任务栏覆盖图标显示计数 |
| 外观 | Mica 背景、标题栏覆盖层、窗口控件位于右上，亮色与暗色 |
| L4 | Electron 应用的 Playwright 流程用例在本机全部通过 |
| R2 平台发现 | R2 评审中与平台相关的发现逐条复核 |

R2 的 W1 检查清单是执行依据：上表是它的基线，清单中多出的项一并执行，并逐条列出 T13–T22 中需要 Windows 证据的 `blocked` 验收项。

### 3. 需要用户操作的步骤

输入法实测、通知点击、首次运行放行需要真人操作。智能体先准备逐步清单（操作、预期、需要回报什么），在会话中请用户执行并回报，结果与截图记入证据目录。输入法守卫另用 CDP 合成事件做自动化测试，作为回归保护。

### 4. 问题处理

- 平台问题先写能在 Windows CI 上复现的失败测试，再在平台适配层修复（Core 的 trait 实现或主进程 `platform/` 模块，业务代码不出现平台分支，第 15.3 节）。
- 无法在本任务修复的问题登记到 `PLAN.md`"登记事项"，写明影响与建议的处理任务。

### 5. 报告

- `docs/reviews/W1-windows-m1-parity.md`：环境与提交号、检查表每项的结果与证据路径、发现的问题与处理、结论（M1 在 Windows 上是否达标）。
- T13–T22 中因需要 Windows 而 `blocked` 的验收项，在报告中逐条给出 Windows 证据。按协议不修改其他任务的验收项，在最终报告中列出这些项，供用户更新。
- `PLAN.md` 写入 W1 结论摘要。

## 实现要点

- 证据统一放在 `tmp/evidence/W1/`，截图文件名对应检查项。
- 长路径与保留文件名的测试夹具在测试中动态创建，不入库（Git 在 Windows 上处理不了这类文件名）。
- Toast 依赖应用标识（AppUserModelID，需求 D2）；标识未落实时记录现象，该检查项标 `blocked`，其余照常进行。

## 验收标准

- [W1-A01] 报告记录了平台（`win32`）、Windows 版本、架构与验收时的提交号。验证：报告内容与命令输出。
- [W1-A02] 与 R2 相同的服务商组合在 Windows 上完成"读代码 → 改代码 → 跑测试"完整任务，工作区路径含空格与中文。验证：会话记录、测试通过输出与截图（`tmp/evidence/W1/`）。
- [W1-A03] 本机运行的 L2 场景不少于 20 个且全部通过。验证：命令输出。
- [W1-A04] Git Bash 被探测并用于 `Bash` 工具；隐藏 Git Bash 后出现安装提示且只提供 `PowerShell`；`PowerShell` 工具可执行且 Manual 下询问。验证：测试输出与截图。
- [W1-A05] 盘符、UNC、含空格与中文、超过 260 字符的路径和保留文件名在文件工具中行为正确；CRLF 文件经 Edit 后换行风格不变；命令输出中的中文不乱码。验证：测试输出与核对记录。
- [W1-A06] 命令超时与停止时整棵进程树被终止，无残留进程。验证：测试输出与 `tasklist` 核对结果。
- [W1-A07] 主密钥存于凭据管理器，重启应用后凭据可读；数据目录位于 `%LOCALAPPDATA%\PiArc\`；数据目录与日志中无明文凭据。验证：测试、目录检查与明文扫描输出。
- [W1-A08] 微软拼音输入法合成期间 Enter、Esc、`/`、`@` 不触发业务，候选上屏正确。验证：CDP 合成事件的自动化测试与用户实机操作记录（截图）。
- [W1-A09] 窗口不在前台时回合完成与等待审批都弹出系统通知，任务栏覆盖图标显示计数。验证：截图与用户确认记录。
- [W1-A10] Mica 背景与标题栏覆盖层在亮色与暗色下显示正确。验证：截图。
- [W1-A11] Electron 应用的 Playwright 流程用例在 Windows 本机全部通过。验证：命令输出。
- [W1-A12] 发现的平台问题已修复并带回归测试，或已登记；`docs/reviews/W1-windows-m1-parity.md` 逐条给出 M1 退出标准的 Windows 证据与结论。验证：报告与登记事项内容。
- [W1-A13] Windows 上 `npm run verify` 通过。验证：命令输出。
