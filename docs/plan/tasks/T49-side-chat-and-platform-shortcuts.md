## 背景与目标

本任务有三块，彼此独立：

- **侧边对话**：在主会话运行时，基于它当前的上下文问一个旁支问题，回答不进入主对话，也不影响主会话后续的请求（FR-CH-08）。
- **macOS App Intents**：让"快捷指令"可以调用 PiArc 的动作，用原生模块实现（架构第 8.8 节，ADR-0013 第 4 条）。
- **Windows 跳转列表**：任务栏与开始菜单图标的右键菜单中列出最近的工作区和常用任务（架构第 8.8 节）。

App Intents 有一个未验证的前提：Electron 应用的主可执行文件是预编译的，App Intents 的元数据需要由 Xcode 工具链生成并放进应用包（扩展或框架），在 ad-hoc 签名下"快捷指令"能否发现这些动作，M0 没有验证过。先用最小的原型确认可行，再做完整实现。不可行属于外部组件行为与架构不符，按变更型处理。

## 范围

### 要做

- 侧边对话：会话内面板、快捷键与内置命令入口、用量统计。
- App Intents：可行性原型、原生模块、打包与签名接入、两三个以打开 PiArc 为结果的动作。
- 跳转列表：最近工作区与常用任务，点击后路由到已运行的实例。

### 不做

- 侧边对话中执行工具，或把回答插入主对话。
- 返回数据给"快捷指令"的动作（例如查询等待审批数），需要应用间通信，不在本版范围。
- 跳转列表的实机显示与点击验证（W4）。

## 交付物

### 1. 侧边对话

- Agent Host 为侧边对话创建临时会话：以主会话当前已完成的历史为上下文，不写入主会话 JSONL，关闭面板后丢弃。
- 侧边对话不执行工具：模型若发出工具调用，Harness Kit 直接返回"侧边对话不能执行工具"，不经过 Core 的 fs、exec 与审批。
- 主会话运行中也能使用，互不阻塞；侧边对话的 token 计入用量统计并单列。
- 入口：快捷键 Mod+;（登记在快捷键注册表，可自定义）与内置命令 `/btw`；面板可停靠，支持停止与复制回答。

### 2. App Intents 可行性原型

- 最小原型：一个动作，打开 PiArc。验证构建、放入应用包、ad-hoc 重签后，"快捷指令"能否列出并运行它。
- 结论写入 `docs/engineering/app-intents.md`（构建方式、签名、已知限制）。
- 不可行时：写 ADR 提议（例如退为提供 `piarc://` 链接的"打开 URL"快捷指令用法），停止 App Intents 部分，完成本任务其余部分，相关验收项标 `blocked`。

### 3. App Intents 正式实现

- 动作：打开工作区；在工作区中新建会话（可带初始文字）。动作经 T35 的 `piarc://` 路由执行。
- 外部触发只预填输入框，从不自动发送：与 URL scheme 的安全语义一致，防止外部来源直接驱动 agent。
- 原生模块的构建并入 macOS CI 与打包流程；`check-fuses.mjs` 与 ad-hoc 重签照常通过。

### 4. Windows 跳转列表

- 分类"最近的工作区"（来自 Core 的工作区表）与任务"新建会话""打开文件夹"；工作区增删时更新。
- 点击后的启动参数经单实例锁的 `second-instance` 事件路由到已运行实例，同样只预填、不发送。
- AppUserModelID 与 Velopack 创建的快捷方式一致，否则跳转列表不显示；把这一点写进主进程 `platform/` 的 CLAUDE.md。

## 实现要点

- 侧边对话的请求尽量复用主会话的 system 与工具定义前缀，以命中 prompt cache；用 mock provider 记录前缀是否一致，作为报告数据。
- 平台代码只放在主进程的 `platform/` 模块和原生模块中，业务代码不出现平台分支（第 8.8 节末条）。
- 实机关口的清单要具体：在哪里添加动作、填什么参数、期望看到什么、把什么结果截图告诉你。

## 验收标准

- [T49-A01] 侧边对话的请求包含主会话当前已完成的历史。验证：mock provider 请求断言。
- [T49-A02] 一次侧边对话问答前后，主会话的 JSONL 字节不变，主会话下一个请求中不含侧边对话的任何内容。验证：文件比对与 mock provider 请求断言。
- [T49-A03] 侧边对话中模型发出工具调用时，工具不执行，Core 没有收到 fs、exec 或审批请求。验证：L2 场景。
- [T49-A04] 主会话运行中打开侧边对话并完成问答，主会话的回合事件与排队项不受影响。验证：Playwright 与 mock provider。
- [T49-A05] 快捷键与 `/btw` 都能打开侧边对话，快捷键可自定义，关闭后内容丢弃。验证：Playwright 与截图（`tmp/evidence/T49/`）。
- [T49-A06] 侧边对话的 token 用量计入统计并单独列出。验证：测试。
- [T49-A07] App Intents 可行性结论已写入 `docs/engineering/app-intents.md`；不可行时 ADR 提议已写。验证：文件内容。
- [T49-A08] App Intents 原生模块在 macOS CI 上构建并打入应用包，ad-hoc 重签后应用正常启动，fuse 检查通过。验证：CI 输出与 `check-fuses.mjs` 输出。
- [T49-A09] 用户在"快捷指令"中能看到 PiArc 的动作，运行"新建会话"后 PiArc 打开对应工作区并预填文字，未自动发送。验证：用户实机操作记录与截图。
- [T49-A10] App Intents 与跳转列表触发的启动只预填输入，不发送消息。验证：测试。
- [T49-A11] 跳转列表条目的生成与启动参数路由有单元测试，并在 Windows CI 上通过；实机显示与点击由 W4 验证。验证：Windows CI 测试输出。
- [T49-A12] `npm run verify` 通过。验证：命令输出。
