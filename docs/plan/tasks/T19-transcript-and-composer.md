## 背景与目标

T09 用合成事件流验证了 transcript 渲染与 composer 的可行性（S1），选定了虚拟化列表与 Markdown、高亮方案。本任务把原型接入 Core 的真实事件流，做出 P0 的全部行类型与正式版 composer，并在真实数据下重新确认第 11 章的流式与滚动预算。

UI 只呈现 Core 给出的语义（架构原则 8）：item 状态、错误分类、重试次数都来自事件，界面不自行推断。

完成后，用户可以在会话中流式看到回复、思考、工具调用与 bash 输出，用 composer 提及文件、附加图片与 PDF、在运行中 steer 或排队、随时停止。

## 交付物

### 1. Transcript

- 打开会话时用 `transcript_window` 加载历史，之后按条目增量更新；切换会话时已缓存的会话直接显示。
- P0 行类型（第 8.2 节），每种一个组件：

| 行类型 | 要求 |
|---|---|
| 用户消息 | 显示附件与文件提及胶囊 |
| 回复正文 | Worker 中增量 Markdown 与代码高亮（T09 的管线），原始 HTML 当文本 |
| 思考块 | 生成中强制展开、不能折叠；结束后折叠为"思考了 N 秒" |
| 工具组摘要 | 动词 + 对象 + 增删计数，可展开 |
| bash 卡 | 命令、cwd、语义状态、退出码；超过 10 秒显示计时；截断时给出落盘提示 |
| 文件改动卡 | 文件路径、增删行数、结构化 diff 预览 |
| 压缩提示 | 原因与压缩前后 token 数 |
| 错误卡 | 按 Core 给出的 `kind` 分类显示，`retryable` 时提供重试 |
| working 行 | 当前工具、计时、token 数、重试次数（n / max）、正在压缩 |

- Agent Host 重启导致回合状态为 `uncertain` 时，显示"连接中断，回合状态未知"并提供重试（第 7.5 节）。

### 2. Composer

- `@` 文件提及：Core API 对工作区文件做模糊匹配（遵守 `.gitignore`，结果数有上限，查询可取消）；提及以胶囊显示；胶囊的存储数据、显示形态、发送时拼接的文本三者分开。
- `/` 命令面板：列出 Core 提供的内置命令（M1 至少 `/clear`、`/compact`、`/help`），模糊过滤；后续任务注册的命令自动出现。
- 附件：图片（PNG、JPEG、GIF、WebP）与 PDF 支持拖放和粘贴；内容经主进程交给 Core 存入会话目录，输入中只带引用（ADR-0009 第 8 条）；类型与大小上限集中定义。
- 发给模型时，图片作为图像内容；PDF 在 pi-ai 与当前模型支持文档输入时作为文档内容，否则复用 T16 的 PDF 文本提取（实现时核实 pi-ai 锁定版本对 PDF 输入的支持，结论写进 CLAUDE.md）。
- 运行中 Enter 为 steer、Mod+Enter 为排队、Esc 停止；排队项在 composer 上方列出，可编辑、删除。
- 输入法守卫：合成期间 Enter、Esc、`/`、`@` 都不触发业务（`isComposing` 与 `keyCode === 229`）。

### 3. 错误、复制与选择

- 未送达的消息（Core 未确认接收）标为未送达，可重发；重发不产生重复消息。
- 自动重试显示次数，用尽后转为手动重试按钮（第 8.5 节）。
- 复制本条消息：Markdown（源文本）与纯文本（渲染后的文字）两种；"选中本回合"选中该回合全部行。

### 4. 节奏与滚动参数

流式字符节奏、滚动跟随的解除与恢复阈值、"回到底部"按钮阈值作为常量集中定义，在真实事件流下定稿，写进 transcript 模块的 CLAUDE.md。

## 实现要点

- 流式增量只让最后一个 item 重新渲染（T18 的 store）；已完成的行做记忆化。
- 历史与实时事件用同一套行组件与归约器，避免两条渲染路径。
- 性能测量用真实 Core 与 mock provider：脚本以 100 token/s 输出文本、思考与工具调用的混合内容；滚动测试用 1 万条 item 的会话夹具。
- XSS 载荷集（T09 建立）扩展到真实数据路径：回复正文、工具输出、bash 输出、文件路径。

## 验收标准

- [T19-A01] 九种 P0 行类型各有组件测试，亮暗两套截图存于 `tmp/evidence/T19/`。验证：测试输出与截图。
- [T19-A02] 思考块在生成中保持展开且折叠操作无效，结束后折叠为"思考了 N 秒"。验证：组件测试。
- [T19-A03] working 行在 mock 脚本运行中依次显示当前工具、计时、token 数、重试次数（n / max）与压缩状态。验证：Playwright 流程与截图。
- [T19-A04] `@` 提及的模糊匹配遵守 `.gitignore`、结果数不超过上限；选中后显示为胶囊，发送给模型的文本与胶囊存储数据分开且内容正确。验证：Core 单测、Playwright 流程与 mock provider 请求断言。
- [T19-A05] `/` 命令面板列出内置命令并支持模糊过滤；输入法合成期间输入 `/`、`@`、Enter、Esc 不触发面板、提及、发送或停止。验证：单测与 Playwright 流程。
- [T19-A06] 拖放与粘贴图片、PDF 后附件出现在消息中，模型请求中带有对应内容（图片为图像内容，PDF 按交付物 2 的方式）；超过大小上限或类型不支持时给出提示且不发送。验证：Playwright 流程与 mock provider 请求断言。
- [T19-A07] 运行中 Enter 发送的内容作为 steer 进入当前回合，Mod+Enter 进入排队并可编辑、删除，Esc 停止回合。验证：Playwright 端到端与 mock provider 请求断言。
- [T19-A08] 注入认证失败、限流用尽、Agent Host 中断三类错误时，错误卡分类正确，重试按钮与 `uncertain` 提示可用；未送达消息重发后只出现一次。验证：Playwright 流程（故障注入）。
- [T19-A09] 复制本条消息的 Markdown 与纯文本两种结果正确；"选中本回合"选中范围正确。验证：测试。
- [T19-A10] XSS 载荷出现在回复正文、工具输出、bash 输出、文件路径中时都以文本呈现。验证：安全回归测试。
- [T19-A11] 真实事件流 100 token/s 输出时，渲染进程主线程无超过 50 ms 的长任务，帧时间 p99 ≤ 16 ms。验证：Performance API 测量输出。
- [T19-A12] 1 万条 item 的会话滚动 60 fps；会话切换已缓存 ≤ 100 ms，冷加载 1,000 条 item ≤ 300 ms。验证：测量输出。
- [T19-A13] 滚动跟随的解除、恢复与"回到底部"按钮按定稿常量工作。验证：单测与 Playwright 流程。
- [T19-A14] `npm run verify` 通过。验证：命令输出。
